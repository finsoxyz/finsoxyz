# Hi, I'm Finso!

I build small, self-contained things for the web, usually because I wanted the
thing to exist and could not find it. Most of what lands here is either a
personal project that started as a stubborn idea, or tacoSMP stuff.

I have a soft spot for projects with nothing more than a broad vision.
No plans, just random ideas that get turned into fun experiments.

For full transparency, I am not a seasoned programmer, but I
use Claude Code as crutches for projects while I learn more.

## What I'm building

#### [hylo](https://github.com/finsoxyz/hylo)

A course that builds native metric intuition. Not a conversion trainer: the
goal is to know what 30 degrees or 400 grams actually feels like, without
routing through an imperial figure first. Vanilla HTML and ES modules, no
bundler, self hosted fonts, and it runs offline by opening `index.html`.

#### [wc26-tracker](https://github.com/finsoxyz/wc26-tracker)

Every tier of Claude predicts World Cup 2026 scorelines. The picks get logged
and scored as results come in, to settle which model actually calls it best.

#### [tacosmp-resources](https://github.com/finsoxyz/tacosmp-resources)

Reference material and resources for tacoSMP.
